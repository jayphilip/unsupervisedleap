## SideNote

Margin notes on wide screens, tap-to-reveal inline on mobile. Place `<SideNote>` immediately after the word it annotates — no space before the marker.

The leap of faith is not irrationality<SideNote client:load>Kierkegaard didn't mean *blind* faith. He meant the move you make after reason has genuinely run out — not as a shortcut past thinking, but as the only available move beyond it.</SideNote> — it's the move you make after reason has done all it can.

Unsupervised learning finds structure without labels




<SideNote client:load>In ML terms: clustering, autoencoders, dimensionality reduction — all learn representations from data without being told what the right answer is.</SideNote>, which is closer to how humans actually develop expertise than supervised training is.

## StatBar

Horizontal animated bars. Use `globalMax` to normalise all bars to the same scale. `unit` appends to the value label. Individual bars can take a `color` and a `note`.

<StatBar
  client:load
  title="MMLU Benchmark (% accuracy)"
  unit="%"
  globalMax={100}
  items={[
    { label: "GPT-4o", value: 87.2 },
    { label: "Claude 3.5 Sonnet", value: 88.7, color: "#a78bfa" },
    { label: "Gemini 1.5 Pro", value: 85.9 },
    { label: "Llama 3.1 405B", value: 88.6, note: "Best open-weights model" },

  ]}
/>

## DefinitionBlock

## ArgumentMap

Premise → conclusion tree. `flagged` marks a contested premise in amber. `objection` attaches a red counterpoint inline. `valid` prop shows a green/red badge on the conclusion.

<ArgumentMap
  title="The Orthogonality Thesis Argument"
  conclusion="We cannot assume a superintelligent AI will share human values."
  valid={true}
  premises={[
    {
      text: "Intelligence and goals are orthogonal — any level of intelligence is compatible with any goal.",
      premises: [
        { text: "Intelligence is about optimising efficiently toward goals, not about which goals are chosen." },
        { text: "There is no logical reason a more capable reasoner must converge on human-like values." }
      ]
    },
    {
      text: "A system can be superintelligent at achieving a goal while that goal remains arbitrary from our perspective.",
      objection: "Some argue convergent instrumental goals create de facto value alignment pressure.",
      flagged: true
    },
    {
      text: "Therefore, high capability does not imply benevolence or value alignment."
    }
  ]}/>

## ThoughtExperiment

A styled scenario box for philosophy and ethics posts. Wraps freeform prose in the default slot, ends with a bolded question, and optionally cites the original thinker.

<ThoughtExperiment
  title="The Experience Machine"
  question="If you could plug in and never know the difference, would you?"
  origin="Robert Nozick, Anarchy, State, and Utopia (1974)"
>
  Imagine a machine that can give you any experience you desire. Brilliant neuroscientists have worked out a way to stimulate your brain so that you would think and feel you were writing a great novel, or making a friend, or reading an interesting book. All the time you would be floating in a tank, with electrodes attached to your brain.

  Should you plug in? The machine offers maximum subjective happiness. You would never know you were missing anything. And yet most people hesitate.
